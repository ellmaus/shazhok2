# Шажок 🌱

Telegram-бот + Mini App — помощник по бытовым делам без перегруза.

> Тебе не нужно справляться со всем. Давай найдём одно маленькое действие, которое можно сделать прямо сейчас.

«Шажок» не превращает человека в продуктивную машину. Он помогает поддерживать приемлемый уровень бытового комфорта с учётом реальных возможностей: сначала спрашивает, сколько у тебя сил, и предлагает одно посильное действие вместо огромного списка.

## Что внутри

| Часть | Описание |
| --- | --- |
| **Выбор энергии** | Три уровня («Совсем мало» ☁️, «Немного сил» 🌤️, «Много сил» ☀️) + «Не знаю» 🌫️. Уровень можно менять в любой момент. |
| **Библиотека сценариев** | 9 категорий и 42 готовых бытовых сценария с пошаговыми инструкциями. У многих есть варианты под разные уровни энергии. |
| **Пошаговая инструкция** | Показывает один шаг за раз, а не список из 20 пунктов. Можно остановиться в любой момент. |
| **Свои задачи** | Конструктор собственных задач + избранное (сохранённые сценарии). |
| **История побед** | Мягкая статистика «маленьких побед» без рейтингов продуктивности и серий дней. |
| **Восстановиться** | Отдельный режим самоподдержки: вода, тишина, свет, удобная поза — без уборки. |
| **Мягкие напоминания** | Telegram-бот присылает ненавязчивые напоминания по расписанию, с лимитом частоты и кнопкой «выключить». |
| **Доступность** | Палитры (включая низкоконтрастную и тёмную), размер текста, контраст, отключение анимаций, «простой режим». |

## Структура проекта

```text
shazhok/
├── bot/             # Node-бэкенд: grammY-бот + REST API + планировщик напоминаний + JSON-хранилище
│   └── src/
│       ├── index.ts        # точка входа: бот, HTTP-сервер, планировщик
│       ├── httpServer.ts   # /api/* и раздача собранного Mini App
│       ├── db.ts           # JSON-хранилище (bot/data/db.json)
│       ├── auth.ts         # проверка подписи initData от Telegram
│       ├── reminders.ts    # планировщик мягких напоминаний
│       └── types.ts        # типы бэкенда
└── webapp/          # React + Vite Mini App (Telegram WebApp)
    └── src/
        ├── data/           # сценарии, категории, уровни энергии
        ├── screens/        # 5 вкладок + пошаговая инструкция и оверлеи
        ├── components/     # карточки, навигация, переключатели
        ├── store.ts        # состояние (zustand + localStorage)
        └── api.ts          # клиент бэкенда
```

## Требования

- Node.js 18+ (рекомендуется 20+)
- pnpm 9+
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

## Быстрый старт

### 1. Установка

```bash
cd shazhok
pnpm install
```

### 2. Токен бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. Скопируй конфиг:

```bash
cp bot/.env.example bot/.env
```

3. Впиши в `bot/.env`:

```env
BOT_TOKEN=123456789:AA...твой-токен
WEBAPP_URL=https://ваш-туннель.trycloudflare.com
PORT=3001
```

`WEBAPP_URL` — HTTPS-адрес, по которому будет открываться Mini App. Для локальной разработки это URL туннеля.

### 3. Туннель (для локальной разработки)

Telegram Mini App требует HTTPS. Самый простой способ — Cloudflare Tunnel:

```bash
cloudflared tunnel --url http://localhost:3001
```

Полученный `https://….trycloudflare.com` впиши в `WEBAPP_URL` и в BotFather.

### 4. Запуск

**Режим разработки** (бот на :3001, Mini App с hot-reload на :5173, `/api` проксируется):

```bash
pnpm dev
```

**Продакшн-подобный режим** (собирает Mini App и раздаёт его с ботом на одном порту):

```bash
pnpm build
pnpm start
```

После `pnpm build` бэкенд сам раздаёт `webapp/dist` и API на одном порту (`PORT`, по умолчанию 3001). Один туннель покрывает всё.

### 5. Регистрация Mini App в BotFather

1. `/mybots` → выбери бота → **Bot Settings → Menu Button** → задай URL Mini App (= `WEBAPP_URL`).
2. Или просто пришли боту `/start` — кнопка «Открыть Шажок» появится из ответа бота.

## Как устроены напоминания

- Включаются в Mini App: **⚙️ Настройки → Мягкие напоминания**.
- Время — несколько точек (например, 09:00 и 18:00), лимит частоты в день.
- Бэкенд каждые 60 секунд проверяет расписание в часовом поясе пользователя и шлёт мягкое сообщение с кнопкой «Открыть Шажок».
- Быстро выключить: команда `/off` в чате с ботом.
- Проверить, что всё работает: кнопка «Отправить тестовое напоминание» в настройках.

## Идентификация пользователя

Mini App отправляет бэкенду `initData` от Telegram WebApp; бэкенд проверяет подпись (HMAC-SHA256) и достаёт id пользователя. В браузере без Telegram приложение работает в режиме предпросмотра: данные хранятся локально в `localStorage`, а запросы к API идут с `X-Dev-Id: dev-user`.

## Деплой на Render / Railway

Самый простой способ открыть Mini App с телефона без туннелей — развернуть всё на бесплатном хостинге. Бот сам раздаёт Mini App + API на одном порту, а webhook держит сервис «живым».

**Render:**

1. Залей проект в GitHub-репозиторий.
2. Render → **New → Web Service** → подключи репозиторий.
3. Настройки сервиса:
   - **Root Directory** — `shazhok` (если репозиторий и есть папка `shazhok`, оставь пустым).
   - **Build Command** — `npm run build`
   - **Start Command** — `npm run start`
   - **Environment Variables:**
     - `BOT_TOKEN` — токен от @BotFather (обязательно).
     - `WEBAPP_URL` — можно не задавать: бот возьмёт его из `RENDER_EXTERNAL_URL` автоматически.

4. Render выдаст адрес вида `https://<имя>.onrender.com` — это и есть `WEBAPP_URL` Mini App.

**Railway** — то же самое: Build Command `npm run build`, Start Command `npm run start`, переменные `BOT_TOKEN` (+ при желании `WEBAPP_URL`).

Как это работает: при наличии `RENDER_EXTERNAL_URL` (или явного `WEBHOOK_URL`) бот автоматически переключается с long polling на webhook (`POST /webhook`). Это важно для Render free, где сервис засыпает без входящих запросов.

> ⚠️ На бесплатном тарифе Render напоминания срабатывают только пока сервис не «уснул» (15 минут без входящих запросов). Для постоянных напоминаний нужен платный тариф или внешний cron-пинг.

## Ограничения MVP

- Хранилище — JSON-файл (`bot/data/db.json`), не СУБД; для сотен пользователей хватает, для продакшна стоит перейти на SQLite/Postgres.
- ИИ-разбивка произвольных задач не подключена — конструктор предлагает простой авто-шаблон («собрать → сделать → прибрать»), а сценарии в библиотеке разбиты вручную.
- Напоминания шлются только тем, кто написал боту `/start` (Telegram требует первого контакта).
- Бот поддерживает два режима: long polling (локально) и webhook (автоопределение по `RENDER_EXTERNAL_URL`/`WEBHOOK_URL` — для деплоя).

## Философия

Не делать приложение ещё одним источником обязанностей. Оно должно помогать человеку жить, а не создавать дополнительную работу по поддержанию самого приложения.
